# Video-Encoder

This simple program takes a video file (.mp4) and reencodes it into h.264 encoding. This is mainly for compatibility with older devices.

Note:
    - You need ffmpeg.exe, you can download that online and reconfigure the path to it yourself.
    - You need to add the program to your Windows Registry so it can be used in the context menu, as the program expects the program to be ran with arguments and args[0] being the target file path.
    - This program isn't intended for other people to use, rather, it's just a personal utility I needed and thus made. Expect difficulties if you are trying to use this program for yourself.
